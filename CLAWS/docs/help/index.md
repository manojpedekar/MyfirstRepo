## What Are These Tools?

### NTFS Permissions Collector

The NTFS Permissions Collector is a PowerShell module that inventories file and folder permissions across your Windows file servers. It captures:

- NTFS access control lists (ACLs)
- Share permissions
- Folder structure and attributes
- Volume and disk information

### AD Inventory Collector

The AD Inventory Collector is a PowerShell module that collects Active Directory data including:

- Users, groups, and computers
- Group membership (including nested groups)
- Forest and domain configuration
- Trust relationships
- Sites, subnets, and site links
- Domain controller information
