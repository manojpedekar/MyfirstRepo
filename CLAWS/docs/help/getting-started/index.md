# Getting Started

Welcome! This section will help you understand the NTFS Permissions and AD Inventory collection tools and get you up and running quickly.

## What You Can Do

With these tools, you can:

1. **Collect NTFS Permissions** - Inventory file and folder permissions from Windows file servers
2. **Collect AD Inventory** - Gather Active Directory objects, group memberships, and configuration
3. **Upload Collections** - Submit your data to this web application for analysis
4. **View Reports** - Analyze permissions and AD data through the web interface

## Choose Your Path
