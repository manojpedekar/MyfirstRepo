# Contact & Support

How to get help with the NTFS Permissions and AD Inventory tools.

## Support Contact

**Global Windows Servers Team**

Email: **GlobalWindowsServers@sscinc.com**

## Before Contacting Support

Please gather the following information to help us assist you faster:

### For Collection Issues

- [ ] Error message (exact text)
- [ ] Collection log file (from the output ZIP)
- [ ] Collector version (`Get-Module CollectNTFSPerms` or `Get-Module ADInventory`)
- [ ] PowerShell version (`$PSVersionTable.PSVersion`)
- [ ] Operating system version
- [ ] What you were trying to collect

### For Upload Issues

- [ ] Error message (exact text)
- [ ] Upload ID (from the status page)
- [ ] Collection filename
- [ ] File size
- [ ] Screenshot of the error (if applicable)

### For Web Application Issues

- [ ] Error message or unexpected behavior
- [ ] Screenshot of the issue
- [ ] Browser and version
- [ ] Steps to reproduce

## Feature Requests

Have an idea for improving the tools?

Send feature requests to: **GlobalWindowsServers@sscinc.com**

Please include:
- Description of the feature
- Use case / why it would be helpful
- Any relevant examples

## Bug Reports

Found a bug? Please report it with:

- Steps to reproduce
- Expected behavior
- Actual behavior
- Environment details (OS, PowerShell version, etc.)
- Screenshots if applicable

## Documentation Feedback

Found an error in the documentation? Let us know:

- Which page has the issue
- What's incorrect or unclear
- Suggested correction (if you have one)
